# Difference-Arrays-ArrayLists

Java arrays are containers and lists of data. The data must be the same type as the one you initialized, followed by opened and closed brackets. 

Example: int[] scores = {2, 4, 5, 8}; 

If you need to store different types of data in a list, then you need to use an array of objects.

Example: Object[] items = {“2”, 4.3, 3};

C++ is similar in the rules and initialization of arrays, but it doesn’t use object[]. Instead, it uses a vector of the type any. 

Example: vector<any> list;

Java ArrayLists are similar to arrays due to the fact that they hold and store data. The difference is how they store data. ArrayList grows and shrinks its size dynamically, while arrays remain static. 

This is highly similar to C++. C++ has its own ArrayList, it’s called vectors.
